# DECISIONS.md — VoiceBridge

Product-level decisions. Workspace-wide decisions (D-01…D-18) live in the parent
`../DECISIONS.md`; these are the ones this repository owns.

| # | Date | Decision | Why | Consequences |
|---|---|---|---|---|
| V-01 | 2026-09-12 | **`POST /v1/voice-answer` stays as a documented compatibility alias** of `POST /api/v1/voice-answer` — same handler, both in the OpenAPI document. | ElevenLabs agents already in the field are configured against the original bridge URL; breaking them to satisfy a versioning rule would be cosmetic purity at the cost of a working demo. | Two spec paths, one implementation; a contract test asserts both. The alias is marked as compatibility-only and new integrations are pointed at `/api/v1`. |
| V-02 | 2026-09-12 | **The prospect registry moves from a committed JSON file to `DATA_DIR/prospects.json` with admin CRUD.** The repo ships `config/prospects.example.json` (placeholder agent ids), which seeds the store on first boot. | The old flow needed a redeploy (or an unauthenticated `POST /admin/reload`) to add a prospect, and the committed file carried real Knowledge Box and agent ids. | `POST /admin/reload` is gone. A Fly volume holds the registry. `VOICE_DEFAULT_AGENT_ID` injects the real agent id into the first seeded prospect so the deployed demo keeps working without committing it. |
| V-03 | 2026-09-12 | **One ARAG client per Knowledge Box + zone (`AragClientPool`), not one per process.** | VoiceBridge is multi-tenant: prospects can sit in different Knowledge Boxes and different zones. A single global client cannot express that. | The pool is cleared whenever the registry changes. All prospects share one service-account token today; per-prospect credentials are a documented extension point. |
| V-04 | 2026-09-12 | **The handoff contract stays a sentinel string (`HANDOFF:`) agreed with the prompt**, backed by empty-answer and empty-retrieval checks. | Deterministic and debuggable: the bridge never has to judge whether an answer is "good enough", and the behaviour is reproducible in the golden set. | The prompt and `src/services/handoff.ts` must change together. Stock refusal phrasings are also matched, so a stored configuration that omits the prompt still degrades safely. |
| V-05 | 2026-09-12 | **Per-route rate limits in product code** (`RateLimiter`) on `/api/v1/brief` and `/api/v1/scribe-token`, on top of the platform's global per-IP limiter. | The brief fires every ~1.5 s while listening and each call costs an LLM generation; a scribe token costs ElevenLabs quota. One global budget cannot cover both these and a normal turn. | A small product-owned limiter; reported to the platform team as a gap (per-route limits belong in the toolkit). |
| V-06 | 2026-09-12 | **`POST /api/v1/scribe-token` always requires a session, API key or admin token**, even when `API_KEYS` is unset. | It mints third-party credentials. "Open by default" is right for reading prospects, wrong for spending someone else's quota. | The console calls `POST /api/v1/session` at boot; the flow is documented for other clients. |
| V-07 | 2026-09-12 | **The demo's primary path is a text turn tester, not a phone call.** | The wow moment must work with zero credentials and inside a recorded walkthrough: type a question, see the spoken line, the citations, the latency and the handoff badge. Voice modes remain, one tab away. | The mock ARAG is seeded with eight short additive-manufacturing documents so the `progress` golden set passes offline; `make showcase` records against the mock. |
| V-08 | 2026-09-12 | **The turn log stores the question text only for turns that passed the input guard.** | An injected or unsafe prompt is exactly the text you do not want to retain and re-display in an admin panel. | Guard trips record the reason, latency and prospect; the admin panel shows "redacted (guard trip)". An e2e test asserts it. |
| V-09 | 2026-09-12 | **The ElevenLabs browser client is vendored** (`public/vendor/elevenlabs-client.js`, pinned 1.14.0 IIFE bundle) instead of imported from esm.sh at runtime. | Supply-chain control, offline reliability and a narrow CSP; a CDN import is a live code-execution dependency on a third party. | Licence recorded in `THIRD_PARTY_NOTICES.md`; re-vendoring is a documented two-step. |
| V-10 | 2026-09-12 | **Golden evaluations run in-process as jobs** against the same pipeline, with persisted history — not as a CLI that HTTP-calls a running server. | The gate should measure the code path the agent uses, be runnable from the console and the admin panel, and leave an auditable record. | `POST /api/v1/golden-evals` returns a job; `scripts/eval.ts` is a thin client over it for CI. |
| V-11 | 2026-09-12 | **`VOICE_TURN_TIMEOUT_MS` is a product variable, separate from `ARAG_TIMEOUT_MS`.** Boot fails if it is not below `AGENT_TOOL_TIMEOUT_MS`. | The platform default (60 s) is right for a document pipeline and fatal for a voice turn: the agent gives up at 8 s and the caller hears silence. | Documented in `.env.example` and asserted at startup; the brief keeps its own longer budget. |
